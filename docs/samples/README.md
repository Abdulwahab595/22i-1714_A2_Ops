# API demonstration inputs

The two JPEGs are unchanged public dataset examples. Their source paths, folder labels, and SHA-256 hashes are recorded in provenance.json. They were selected as correct examples for the interface demonstration; the reported accuracy uses all 147 held-out images, including errors.
